# AWESOME · AI-маркетолог

MVP для хакатона «Кибер 102». Go backend, Python Telegram transport, Vue 3 Mini App. Генерация текста работает через **существующий аккаунт ChatGPT в Codex CLI**, без отдельного OpenAI API-ключа.

## Что реализовано

- Задачи на естественном языке в Telegram и в Mini App.
- Отдельные профили компаний, база знаний, история и каналы.
- Загрузка PDF/TXT/MD через бота, TXT/MD через админку.
- Генерация текста с учётом компании и последних сообщений.
- PNG-карточки: ChatGPT задаёт заголовок, подзаголовок, цвет и композицию; Pillow рисует изображение. Это **не фотореалистичная генерация image-моделью**.
- Одобрение, отклонение, доработка с комментарием и ручное редактирование.
- Одобрение связано с версией. Любые правки отменяют согласование.
- Публикация в Telegram, ссылка на результат, задачи по расписанию.
- Сохранение состояния после перезапуска и журнал событий.
- Проверка подписи Telegram initData, срока действия и доступа к компании.

## Быстрый локальный запуск

Требуются Go 1.23+, Node 22+, Python 3.10+, Codex CLI 0.168.0.

```bash
npm install -g @openai/codex@0.168.0
codex login
cp .env.example .env
# Заполните .env. INTERNAL_TOKEN — случайная строка минимум 32 символа.
# ADMIN_IDS — числовые Telegram ID, через запятую.
# Для локального кабинета можно задать LOCAL_ADMIN_TOKEN=<случайный секрет>.
./scripts/dev.sh
```

Кабинет: http://127.0.0.1:8080. Локальный вход работает только на loopback-хосте без forwarded-заголовков и при явно заданном LOCAL_ADMIN_TOKEN. Для Telegram нужен PUBLIC_URL с HTTPS. Бот при старте настраивает меню **«Открыть»** через setChatMenuButton.

Кнопка запуска приложения **в профиле бота** настраивается дополнительно владельцем через BotFather → /mybots → бот → Bot Settings → Configure Mini App → Enable Mini App. Укажите тот же PUBLIC_URL. Это отдельная настройка от меню «Открыть» в чате.

## Развёртывание на сервере

1. Установить Docker Engine и Compose plugin, открыть TCP 80/443 и SSH для администратора.
2. Скопировать проект, создать `.env`, задать DOMAIN и PUBLIC_URL. Домен должен указывать на IP сервера.
3. Собрать образ и авторизовать ChatGPT:

```bash
docker compose build
docker compose run --rm --no-deps backend codex login --device-auth
# Владелец аккаунта открывает адрес из вывода и вводит одноразовый код.
docker compose up -d
docker compose ps
docker compose logs --tail=50 backend bot
```

Caddy получает HTTPS-сертификат автоматически. Бот не публикует при отсутствии одобрения. Не запускайте одновременно две копии Telegram polling для одного токена.

Проверка: `curl https://<DOMAIN>/healthz`. Все /internal/* и /api/local-session закрыты публичным reverse proxy. На сервере LOCAL_ADMIN_TOKEN отключён.

## Сценарий демонстрации (5–7 минут)

1. Открыть @awesomesmm_ai → /start → «Открыть».
2. В разделе «Компания» заполнить факты, аудиторию и стиль; сохранить.
3. Отправить: «Подготовь пост-знакомство о нашей компании».
4. Получить текст и карточку; нажать «Доработать» и прислать комментарий.
5. Получить версию 2; убедиться, что старое одобрение не действует.
6. Одобрить новую версию; открыть ссылку на реальный пост в @awesome_smm.
7. Спросить: «Что мы только что опубликовали?» — ответ учитывает историю.
8. Добавить вторую компанию через интерфейс, задать отличающиеся факты.
9. Создать расписание на ближайшую минуту; показать автономное создание черновика.
10. Перезапустить backend; показать сохранённую историю и задачи.

## Надёжность и ограничения MVP

Данные хранятся в `/data/state.json`: один процесс Go с mutex, атомарная запись через временный файл, fsync и rename. Объём рассчитан на демонстрацию; горизонтальное масштабирование и несколько backend-реплик **не поддерживаются**. Для продукта нужна PostgreSQL и транзакционный outbox.

Telegram Bot API не поддерживает idempotency key публикации. Поэтому при таймауте/перезапуске в момент отправки пост переходит в «Проверьте канал», автоматически не отправляется повторно. Это предотвращает слепые повторы, но требует ручной сверки канала.

Очередь AI обрабатывается последовательно. Генерация ограничена 150 секундами; ошибка отображается с возможностью повтора. Регулярная задача создаёт черновик и требует нового одобрения. После простоя выполняется один пропущенный запуск, без шквала накопленных задач.

История хранится раздельно по компаниям (до 40 последних сообщений), база знаний — текст до 50 КБ. RAG, OCR сканов, автоматический обход сайтов, полноценная image-модель, VK/MAX, аналитика охватов и мониторинг комментариев — следующие этапы. Получение message_id и ссылки является подтверждением доставки, а не показателем охвата.

Доступ к ChatGPT зависит от тарифного плана, доступности аккаунта и его лимитов. Подтверждённая авторизация Codex не означает доступ ко всем инструментам веб-версии ChatGPT. Секреты `.env` и auth-кэш Codex не входят в Git.

## Стоимость

Формула месяца: сервер + действующая подписка ChatGPT + дополнительные usage credits при наличии + хранение/резервные копии. Отдельных API-вызовов в этой реализации нет. До защиты нужно подставить фактическую цену ВМ, тариф аккаунта и измерить лимиты на сценарии «30 текстов + 30 карточек + доработки». Фиксированная цена без этих данных была бы недостоверной.

## Проверки

```bash
(cd backend && go test -race ./...)
(cd frontend && npm ci && npm run build)
python3 -m py_compile bot/main.py bot/render_card.py
```

Тесты проверяют подпись и срок действия Telegram-сессии, изоляцию компаний, запрет публикации отклонённого контента, привязку одобрения к версии, единственную постановку публикации в очередь и восстановление после перезапуска.
